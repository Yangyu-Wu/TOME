# Quaternius Universal Base Characters — male runtime source

- Source: https://quaternius.itch.io/universal-base-characters
- License: CC0 1.0 Universal; the page explicitly permits personal, educational and commercial projects.
- Runtime model: `Superhero_Male_FullBody.gltf` + its `.bin` and referenced PNG textures.
- Compatibility: the source page states compatibility with the Universal Animation Library. The model and UAL2 GLB use matching humanoid node names (including `Head`, `neck_01`, `upperarm_l/r`, `hand_l/r`), so the GPU layer can load the model mesh and animation clips separately.
- This is a high-quality neutral base character for retargeting, not a finished historical Three Kingdoms hero. It is kept as a production-style material/rig candidate while hero-specific armor, hair and weapons are authored.
