# 专属长柄武器

本目录模型由项目以 Three.js 几何体和曲线制作，没有引入第三方武器模型。
文件独立存放：`guandao.js`（关羽）、`halberd.js`（吕布）、`silver-spear.js`（赵云）；`polearm.js` 提供共用的杆、缠柄、金属箍与刃口构建方法。

模型采用源骨架的米制尺度，握柄中心位于原点，绑定右手骨骼，运行时将握柄原点移至掌心并校正横向握持轴。刃根与刃尖锚点供战斗拖尾采样；金属、木杆、玉饰及红缨保留各自材质，不被阵营染色覆盖。

本批为可运行的程序化造型迭代，尚未达到写实高精度武器标准；缺少雕刻烘焙、真实磨损贴图和红缨动力学。已有程序化横扫/下劈/突刺及双手握持控制层，仍缺完整武术表演。模型近景：`tests/weapon-showcase.html`；动作近景：`tests/polearm-motion-showcase.html`。
