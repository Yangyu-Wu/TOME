# 长柄武器动作控制层

`poses.js` 为项目制作的动作关键姿态数据，分别定义关羽横扫、吕布下劈、赵云突刺的蓄力、出手、随动和收势。它不是动作捕捉，也不是新下载的动画。

底层身体动作来自 Quaternius UAL2 CC0 `Idle_Shield_Loop`，重定向后按动作时长生成独立运行时剪辑。上身扭转、武器位姿和副手滑动由控制曲线驱动，`equipment/polearm-grip.js` 使用 `two-bone-ik.js` 约束双手；手臂只旋转，不伸缩。超出双臂可达范围的武器位置被平移回可达区域。受击、冲刺和死亡释放约束，原始骨骼姿态在下一帧混合前恢复。

`retarget-clips.js` 根据动画源和底模各自的绑定姿态处理旋转差异；保留底模肢体长度，根骨/骨盆位移按腿长缩放。UAL1、UAL2 使用相同源骨架，原文件保持不变。

近景检查：`tests/polearm-motion-showcase.html`，支持动作暂停、逐帧进度与绕角色旋转视角。截图工具：`python3 tools/capture-motion.py --hero zhaoyun --phase .53 --view -.8 --output /tmp/spear.png`。

实战攻击时序由纯数据模块 `src/heroes/attack-timing.js` 共享。战斗模拟创建带序号的完整攻击周期，在归一化命中点进行一次伤害判定；GPU 按模拟进度采样动作，Canvas 回退也读取相同进度。加速效果缩短整个周期，单次伤害按原 .3 秒普攻的基准持续输出补偿。该补偿保留理想持续输出，但改变了爆发、过量伤害和打空的影响，仍需继续平衡。

目标锁定到本次攻击，目标死亡、离开范围或绕到身后时挥空；眩晕/死亡/施法取消未完成的攻击。普通轻微受击不打断已经开始的长柄攻击，以免高频敌兵攻击使武将持续无法出手。命中点的热金属火星通过独立 GPU 素材 `effects/melee-impact.js` 渲染，生命周期也由战斗模拟控制。返回营地或开始下一场会清除动作状态。

实战近景：`tests/impact-duel-showcase.html`，可暂停、慢放和拖动攻击进度，同时观察目标血量。截图工具加 `--scene duel`。

当前限制：这些动作是程序化控制层配合通用授权动画，仍缺武术表演级的全身关键帧、步法转换和真实重量传递；命中使用锁定目标、范围与朝向检查，尚非刀刃几何碰撞。其余职业仍沿用原普攻时序，不可作为已完成 3A 动作质量的依据。
